You don't need to learn every AI word to use AI well. But a handful come up again and again, in app settings, news stories and help pages. Here they are in plain English, grouped by where you're likely to meet them.

Each one is kept short on purpose. When a term links to a bigger idea, the entry says so in a sentence, and you can skip the rest.

How AI is built

AI (artificial intelligence): a broad label for software that does tasks we used to think needed human judgment, like spotting spam or writing a paragraph. It covers many different systems.

Machine learning: a way of building software that learns patterns from examples instead of following only hand-written rules.

Model: the trained program at the heart of an AI system. You send it input, and it gives back a prediction or some new content.

Training data: the examples a model learned from before it was released. For a chatbot, that's mostly a huge amount of text.

Parameters: the adjustable numbers inside a model. Training changes them, and together they hold what the model learned.

Neural network and deep learning: a neural network is a model made of many simple connected units. Deep learning means using networks with many layers.

Generative AI: AI that produces new content, such as text, pictures, audio or code.

Language model: a model trained on lots of text to predict which piece of text comes next. A very large one is often called an LLM, short for large language model.

Fine-tuning: training an existing model a bit more on a smaller set of examples, so it gets better at one kind of job.

Open-weight model: a model whose trained numbers are published, so others can download and run it. Many models aren't shared this way and can only be used through an app or a service.

Words you'll meet in a chat

Chatbot: an app you talk to by typing or speaking. Most new chatbots run on a language model.

[ita_term define="The message or instructions you type to an AI app to tell it what you want."]Prompt[/ita_term]: the message or instructions you type to tell the AI what you want. A clear prompt usually gets a more useful answer.

Token: a small piece of text that a model reads and writes. It can be a short word, part of a longer word or a punctuation mark.

[ita_figure name="token-splitting" alt="The sentence Learning AI is fun is split into six pieces: Learn, ing, AI, is, fun and a full stop." caption="Example only: real tools split text in their own ways."]

Context window: how much text a model can take into account at once, counted in tokens. In a very long chat, the oldest messages can fall out of it, so the model may lose track of them.

Memory: a feature in some apps that saves notes about you between chats and adds them to new ones. You can often see and delete these notes in the settings.

Temperature: a setting that controls how much randomness goes into each word choice. Lower usually means steadier, more predictable answers; higher means more variety. Most apps set it for you.

Multimodal: able to handle more than one kind of input or output, for example reading a photo and answering in text.

Mistakes, safety and doing things

Hallucination: when a model states something false or made up as if it were true. It often sounds confident, so check facts that matter.

Bias: unfair patterns in a model's output, often learned from the human-written text it was trained on.

Guardrails: rules and checks built around a model to block harmful output or risky actions.

Tool: on this site, a capability the model can call, like searching the web, reading a file or adding a calendar entry. The chat product itself is called an app.

Agent: a program that uses a model to decide the next step, uses tools, looks at the result and repeats until a goal is met.

[ita_why title="Why do the same words mean different things in different places?"]

AI is a young field that moves quickly, and many words were borrowed from everyday speech. "Memory" in a chat app is a feature that saves notes. In computer hardware it means something else entirely. "Agent" is used for anything from a simple automated helper to a system that works through long tasks on its own.

Some terms are also still argued about. "Hallucination" is popular, but some people dislike it because it makes a model sound like it has a mind. When a word matters, ask what the system actually does.
