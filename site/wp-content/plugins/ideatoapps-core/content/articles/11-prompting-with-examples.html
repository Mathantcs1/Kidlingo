"Fixed leak under kitchen sink, new washer" becomes "Kitchen sink: repaired leak and replaced washer." Show a chatbot two or three pairs like that, and it will usually write the next one the same way.

What an example shows that a description can't

An example in a [ita_term define="The message or instructions you type to an AI app to tell it what you want."]prompt[/ita_term] carries a lot of information at once: the length, the word choice, the punctuation, and what gets left out. Writing all of that as rules would take a paragraph, and the chatbot could still read words like "short" or "professional" differently from you.

One line of your own writing also helps a chatbot match your style; see "Give context, get better answers". A pair of "before" and "after" shows more: a whole change, from rough input to finished output. The chatbot can then repeat that change on new input.

Giving a few worked examples like this is often called [ita_term define="Putting a few worked examples of a task inside the prompt, so the model can follow the same pattern."]few-shot prompting[/ita_term]. Pick examples you were happy with when you sent them.

Build a set of input and output pairs

Here is a set a plumber might use to turn short job notes into lines on a customer's invoice:

[ita_prompt title="Job notes to invoice lines"] Turn each job note into one invoice line for the customer. Follow the pattern in the examples. Use only facts that are in the note. (Example pairs: replace them with your own.) Note: fixed leak under kitchen sink, new washer Line: Kitchen sink: repaired leak and replaced washer. Note: bathroom faucet dripping, replaced cartridge, tested Line: Bathroom faucet: replaced cartridge and tested for leaks. Note: outside drain slow, cleared roots Line: Outside drain: cleared roots from the drain. Note: [paste your next job note here] Line: [/ita_prompt]

A few habits make a set like this work:

  • Same labels every time. "Note" and "Line" appear in every pair, so the chatbot can see where input ends and output begins.
  • Real examples. Take them from past work, and remove customer names and addresses first.
  • An empty output label at the end. The prompt finishes with the new note and a blank "Line:", so the next thing to write is clear.

How many examples?

For a simple format, two or three are often enough. Add more when the task has several kinds of cases, such as repairs, installs and inspections. Each example should cover a different kind of case. Five nearly identical pairs usually teach less than three different ones.

When examples get copied too closely

A chatbot can't tell which parts of your examples are on purpose. It may copy all of them.

Take a creator whose three example captions all end with "What do you think?" New captions will probably end with that question too. If all three examples are about food, a caption about a hiking trip may still mention snacks. If one example has a typo, the typo can come back.

Three habits prevent most of it:

  • Vary the examples in the ways you want the output to vary: topic, length, mood.
  • Say in words which parts are fixed and which are free. For example: "Every caption names the place. The question at the end is optional."
  • Check that your examples follow your own rules. If the instruction says "under 15 words" and an example has 25, the example can win.
[ita_why title="How examples pull the answer toward them"]

A language model writes by predicting likely text, based on everything in the conversation. Your examples are strong evidence of what "likely" means for this task.

The model has no way to know that the repeated question was a coincidence, or that every example being about food was an accident. It treats both as part of the pattern. A written note like "the topic changes every time" tells the model which features to ignore.

Try it

Build an example set with a coworker or friend who writes the same kind of text.

  1. Ask them for three finished pieces of one kind, such as replies to customers or captions. Remove names, and use work text only if your workplace allows it.
  2. Together, write the rough note each piece came from.
  3. Paste them as pairs in the pattern above, ending with a new rough note of theirs and an empty label.
  4. Show them the result and ask what they would change. Add their answer as a written rule above the pairs.
