Take one job: questions about returns at a clothing store. A chatbot can help a staff member write a polite reply. A workflow can run the same planned steps for every return. An agent can read the order, check the rules and decide what to do next on its own.

Three ways to use the same AI

[ita_figure name="chatbot-workflow-agent" alt="Three rows: a chatbot answers one question, a workflow follows fixed steps set by a person, an agent picks its own steps toward a goal." caption="Chatbot, workflow and agent: more freedom needs more checks."]

A chatbot answers you. You type a [ita_term define="The message or instructions you type to an AI app to tell it what you want."]prompt[/ita_term], it replies, and you decide what to do with the answer. If you've ever pasted a customer's question into a chatbot and copied the reply into an email, you've used AI this way. Nothing happens unless you do it.

A [ita_term define="A series of steps and rules that a person plans in advance."]workflow[/ita_term] follows steps a person chose ahead of time. AI may do one of the steps, such as reading a form or sorting an email. The steps and rules are set in advance, even when some steps only run in certain cases.

An agent chooses its own next step. It uses [ita_term define="Capabilities the model can call, like searching the web, reading a file or adding a calendar entry."]tools[/ita_term], looks at the result and repeats until the goal is met or it's stopped. The agent is the model plus the code that runs its tools in a loop (see "What is an AI agent").

Which one does a task need?

Many people use more than one of these at work without naming them. Ask these three questions in order. The examples come from a store's sales floor, but the same questions work for an office, a warehouse or a care home.

Is it a one-off?

A shift lead needs a notice telling staff about a new break schedule. It's written once, and a person reads it before it's posted. A chatbot is enough.

Does it happen the same way every time?

Every online order needs a packing slip and a confirmation message. The steps never change, so a workflow fits. AI might write the message, but the steps stay as planned.

Do the next steps depend on what it finds?

A customer writes that a jacket bought as a gift arrived damaged, and asks for a different size. Someone has to read the order, check the return rules and check stock in other stores. Then they decide whether to offer an exchange, a refund or a question back to the customer. What happens next depends on what each check finds, so this is agent work. A person should still approve the decision before anything is sent.

When a mistake would be costly, the option with fewer free choices is usually safer. A planned workflow is easier to test than an agent. The three also take different amounts of work to set up. A chatbot needs none. A workflow takes time to build, and then it runs by itself. An agent needs tools, permissions and testing before it should touch real work.

You can also ask a chatbot to sort your own tasks. Its labels are a starting point, so change any that don't match how the task works in your job.

[ita_prompt title="Sort my tasks"] Here are some tasks from my job: [task 1] [task 2] [task 3] For each task, say which fits best: asking a chatbot, a workflow with fixed steps, or an agent that chooses its own steps. Give one reason for each, in one line. Then name the task where a mistake would cause the most harm. [/ita_prompt] [ita_why title="How a workflow can use AI without becoming an agent"]

A workflow can include an AI step that makes a choice. For example, AI reads each return request and sorts it into one of three groups a person designed: refund, exchange or needs a staff member. Each group leads to a fixed next step.

The AI chooses, but only among options someone planned. It can't add a new step or use a tool that isn't in the plan. Because every branch is known in advance, you can test each one before the workflow is used.

Try it

Do this at the end of a shift or a work week, while the tasks are fresh in your mind. A pen and a page are enough.

  1. Write down four tasks from your work week. For example: answering questions about opening hours, sending shift reminders, ordering stock, writing a staff notice.
  2. Next to each, write chatbot, workflow or agent, using the three questions above.
  3. Rank the four by how much harm a mistake would cause, worst first.
  4. For the top task, write who would check the AI's work, and at which step.
