A formula that adds the wrong column still gives you a number. It looks just as neat as the right one, and nothing on the screen warns you. A chatbot can write spreadsheet formulas in seconds, so the useful habit is a quick test on rows where you already know the answer.

Where a formula goes wrong

Most formula mistakes don't cause an error message. The formula runs, a number appears, and the number is wrong. Ask for every part of the formula to be explained in plain words, so you can see which cells it really uses.

[ita_why title="Why a formula can look right and still be wrong"]
  • The range stops short. A formula for rows 2 to 50 ignores row 51 when you add it later.
  • Numbers are stored as text. "3.5 h" looks like a number, but a sum usually skips it.
  • References move. When you copy a formula down, cell references shift unless they're marked as fixed, often called absolute references.
  • Settings change the meaning. Decimal commas and the order of day and month depend on the sheet's language settings, so the same entry can be read differently.
[/ita_why]

Say which spreadsheet program you use, too. Formula names can differ between programs, and some language settings use a semicolon instead of a comma between a formula's parts.

Ask with made-up rows, then check by hand

You usually don't need to paste your data to get a working formula. A chatbot needs the column names, what one row means and a few made-up rows in the same format. Leave out names, phone numbers and pay; What not to paste into an AI tool lists the rest.

The owner of a small landscaping company tracks crew hours in a sheet and wants a monthly total for each crew. Their [ita_term define="The message or instructions you type to an AI app to tell it what you want."]prompt[/ita_term] can use made-up rows that look like the real ones:

[ita_prompt title="Formula with a hand check (example values: replace them)"] I use [name of your spreadsheet program]. My sheet has these columns: [A: Date, B: Crew, C: Job type, D: Hours]. Each row is [one job by one crew on one day]. Here are three made-up rows in the same format: [2026-03-02, North, Mowing, 3.5] [2026-03-02, South, Planting, 6] [2026-03-03, North, Planting, 4] Write one formula that [totals the hours for each crew in March]. Explain in plain words what each part of the formula does. Then give the result for the three rows above. [/ita_prompt]

For these rows, North should come to 7.5 hours and South to 6. Work that out yourself before you read the reply. Then test in this order, on a copy of the sheet:

  1. Check the formula on the made-up rows, where you already know the answer.
  2. Run it on the real data and check three rows by hand.
  3. Compare the grand total with a total you get another way, such as selecting the column and reading the sum the program shows.
  4. Add a tricky row: a blank cell, a number typed as text or a date in a different format.

The same care applies when you upload a sheet and ask for a summary or a chart. Some apps calculate with code, while others may write the numbers as predicted text, and you often can't tell which happened. Ask how each figure was worked out, then redo one of them yourself.

Cleaning and reading sheets

Cleaning a messy column

Ask for the steps, or a formula, that clean the column. That works better than pasting the column and getting a cleaned copy back, because a pasted copy can return with rows missing or changed. Count the rows before and after any cleanup.

If you ask for a table as text, it may arrive as [ita_term define="A plain-text table where commas separate the columns."]CSV[/ita_term]. When it lands in a single column, Asking for tables, checklists and JSON shows how to split it.

Understanding someone else's sheet

You've probably opened a sheet built by a coworker and found a formula nobody could explain. Paste only that formula and ask what each part does. You can also ask how to build a [ita_term define="A built-in table that groups rows and totals them, for example hours per crew per month."]pivot table[/ita_term] for a summary, and then build it yourself.

Try it

  1. Make a copy of a sheet you use at work, if your workplace allows it, or start a new sheet with five made-up rows.
  2. Put the column names and three made-up rows into the request above, and ask for one formula you really need.
  3. Work out the answer for those three rows by hand before you read the reply.
  4. Paste the formula into the copy and compare its result with your hand answer.
  5. Add one tricky row, such as a blank cell or a number typed as text, and check whether the result still matches.
