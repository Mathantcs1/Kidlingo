A large language model is trained in two broad phases. First, it learns to predict the next piece of text (a token) across a huge collection of writing. Then it's trained further to act as a helpful assistant, using example conversations, people's judgments and practice on tasks with clear answers.

Pretraining: guessing the next token

The first phase is called [ita_term define="The first and largest training phase, in which a model learns to predict the next token of ordinary text."]pretraining[/ita_term]. It starts with collecting text: public web pages, books, code and other sources. Developers filter it, for example to remove duplicate pages and low-quality text. The exact mix is not always published.

The text is split into tokens. Then the training loop runs, again and again:

  1. The model sees a stretch of real text with the next token hidden.
  2. It gives a likelihood to every token that could come next.
  3. Its guess is compared with the real next token.
  4. Its [ita_term define="The very large set of numbers inside a model that training adjusts."]parameters[/ita_term] are changed slightly, so the real token becomes a little more likely next time. In practice, this happens after each batch of many guesses.

After a huge number of these small changes, the model has learned grammar, many facts and the usual ways people explain things. This runs on large groups of specialized chips for weeks or months.

The result is a [ita_term define="A model that has only been pretrained, so it continues text instead of following instructions."]base model[/ita_term]. It continues text well, but it doesn't reliably answer you. Give it a [ita_term define="The message or instructions you type to an AI app to tell it what you want."]prompt[/ita_term] such as "How do I boil an egg?" and it might continue with more cooking questions, as if it were copying a list from a forum.

Post-training: becoming an assistant

You've probably noticed that chatbots answer in tidy, polite paragraphs and follow your instructions most of the time. That behavior comes from the second phase, which can include these parts.

Learning from example conversations

The model is trained on many example exchanges: a request, then a good reply. People write or check many of them. From these, the model learns the shape of a helpful answer, how to follow instructions and when to decline a request. This is a form of [ita_term define="Training an existing model further on a smaller, focused set of examples."]fine-tuning[/ita_term].

Learning from preferences

Next, the model writes two or more answers to the same request, and people pick the one they prefer. Those choices are used to push the model toward answers people rate higher. Developers also train for safety at this point, for example to refuse some harmful requests.

Practice on checkable tasks

Many developers now add practice on tasks with answers a program can check, such as math problems or code that must pass tests. The model is rewarded when the result is right. This trains it to work through problems step by step.

Developers don't publish every detail and change their methods often, so read this as the general pattern.

[ita_why title="How people's choices become training"]

One common method first trains a separate [ita_term define="A model trained to predict how highly people would rate an answer."]reward model[/ita_term]. It learns from people's comparisons to give any answer a score that predicts how much people would like it.

The main model then writes answers, the reward model scores them, and the main model is tuned toward higher scores. Other methods skip the reward model and learn from the comparisons directly. Some developers also use a list of written rules, with feedback produced by other AI models.

[/ita_why]

What this means when you use or build with a model

Training happens before release. Does a chatbot learn from your corrections? No: your chats don't change the model's parameters. Some apps can save notes about you, but that adds text to later chats; it isn't training. Whether your chats are used to train later models depends on the provider and your settings, which you can usually find in the privacy settings.

If you build with a model, the main choice is between fine-tuning it on your own examples and sending the right information with each request. Fine-tuning tends to work better for a fixed format, a tone or one narrow task. For facts that change, sending the current information is usually easier to update.
