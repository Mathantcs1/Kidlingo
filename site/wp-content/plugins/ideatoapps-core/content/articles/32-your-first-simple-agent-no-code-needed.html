Can you plan an agent without writing any code? Yes. Every agent needs the same five answers: what it's for, what it reads, what it may do, when it must ask you, and when it stops. You can write all five on one page before you open any app or type a single [ita_term define="The message or instructions you type to an AI app to tell it what you want."]prompt[/ita_term]. You've probably done some of this already, every time you explained a task to someone new.

Step 1: the goal and the inputs

An [ita_term define="A program that uses an AI model to choose steps, use tools and repeat them until a goal is met."]agent[/ita_term] works toward a goal on its own, so the goal has to be clear. Write it in one sentence that says what "done" looks like.

Say you post a cooking video every week and get many comments. If you've ever opened them on a Monday and found more than you could answer, this example will feel familiar. Here is a goal before and after some thought:

  • Before: "Help me with my comments."
  • After: "Every Monday, sort last week's comments into questions, praise and spam, and draft a reply to each question."

The second goal says when the agent runs, what it works on and what it hands back. You could check its work against that one sentence.

Next, list the inputs. These are the things the agent needs to read. For the comment roundup, that's the comments on one video, plus a short note about how you like to reply. Leave out everything else. It doesn't need your messages, your income or other people's private details.

The same planning works at home. A parent might write: "Every Sunday, list the forms to sign and the dates to remember from this week's school emails." The inputs are the school emails, and nothing else from the inbox.

Step 2: tools and approval points

A [ita_term define="Something an agent can do besides writing text, such as reading a file, sending a message or adding a calendar entry."]tool[/ita_term] is an action the agent can take. List each one, and write next to it whether it only reads or also changes something.

  • Read the comments on one video: only reads.
  • Hide a comment as spam: changes something, but you can often show it again.
  • Post a reply: changes something that other people see.

Now mark the approval points, the actions that wait for you to say yes. Anything other people will see, anything that costs money and anything hard to undo belongs there.

For the roundup, posting a reply waits for you. Hiding spam might not, if your platform lets you show a hidden comment again. A creator could plan a second agent the same way: one that drafts a caption and three title ideas from each new video's script. Posting the caption would wait for your yes. For the parent's list, making the list can run on its own, and a reply to the school would wait.

Step 3: the stop rule

An agent repeats its steps until something tells it to stop. A good stop rule has two parts.

  1. When the work is finished. "Stop when every comment has a label and every question has a draft reply."
  2. When to give up and ask. "If a comment is in a language you can't read, or you're not sure it's spam, put it on a list for me and go to the next comment."

The second part matters as much as the first. Without it, an unclear case can make the agent repeat the same step, or push it to guess.

When your page is ready, a chatbot can look for weak spots in it. Copy this and put your own page in place of the example values:

[ita_prompt title="Where would it have to guess? (example values: replace them)"] Here is my plan for a simple AI agent. Goal: [Every Monday, sort last week's comments into questions, praise and spam, and draft a reply to each question.] Inputs: [the comments on one video; a short note about my usual tone] Tools: [read comments; hide a comment; post a reply] Needs my approval: [posting any reply] Stop rule: [stop when every comment has a label and every question has a draft reply] Do not rewrite the plan. List each place where an agent following this plan would have to guess, one per line, and say which part of the plan it belongs to. [/ita_prompt]

Fix each guess by adding one line to your page, or by making the goal smaller.

[ita_why title="What the page has to do with real apps"]

Apps that let you build an agent without code usually ask for the same five parts, under other names. The goal and stop rule often go into a box called instructions. Inputs and tools are often called connections, accounts or actions. Approval points may appear as permissions, or as a setting that asks before acting.

The names and options differ between apps, and they change often. The help text next to each setting usually says which of the five parts it controls.

Try it

Pick one small task that repeats every week, at work or at home. Copy this blank page onto paper and fill in the lines in order. Use plain words, as if you were explaining the job to a new helper.

  • Goal (one sentence, including what "done" means): ____________
  • Inputs (what it reads, and nothing more): ____________
  • Tools (mark each one "reads" or "changes"): ____________
  • Waits for my yes: ____________
  • Stop when finished: ____________
  • Give up and ask when: ____________

When the page is full, circle every tool that changes something other people see, and check that each one is also on the "Waits for my yes" line.
