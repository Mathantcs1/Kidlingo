# Fonts

`inter-latin-wght-normal.woff2` is the Latin subset of **Inter Variable** (weights 100-900), copied from the
`@fontsource-variable/inter` 5.3.0 npm package (a dev-time source only; nothing is loaded from npm or any CDN at runtime).
