WHAT I TESTED (2026-11-26, my own machine, free models only, $0 spent of my $5 OpenRouter balance)
- Setup A: Claude Code pointed straight at a free model on OpenRouter (nvidia/nemotron-3-ultra-550b-a55b:free)
- Setup B: Claude Code through the FreeLLMAPI router (model name "auto")
- Setup C: OpenCode 1.19.6 with the free "Big Pickle" model
- Task 1: a small to-do command line tool, 5 runs per setup
- Task 2: fix a small program with 3 bugs (5 unit tests, 4 failing at the start), 3 runs per setup. A pass = all tests pass AND the test file is unchanged (I checked the file hash myself).
- Result: 24 of 24 passed. This is NOT a benchmark: small tasks, one machine, free models change daily.

WHERE TO GET IT (links and commands checked 2026-11-26)
1) OpenRouter + Claude Code. Official guide: https://openrouter.ai/docs/guides/coding-agents/claude-code-integration
   Create a key: https://openrouter.ai/settings/keys
   export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
   export ANTHROPIC_AUTH_TOKEN="<your OpenRouter key>"
   export ANTHROPIC_API_KEY=""   (must be explicitly empty)
2) FreeLLMAPI (MIT licence): https://github.com/tashfeenahmed/freellmapi
   README quick start (Docker): curl -fsSL https://freellmapi.co/install.sh | bash
   I ran it from source (git clone, npm install, scripts/dev-bootstrap.sh, then start the server).
3) OpenCode (MIT licence): https://opencode.ai  |  source: https://github.com/anomalyco/opencode
   The docs page now shows version 2 (curl -fsSL https://opencode.ai/v2/install | bash). I tested version 1.19.6 (npm install -g opencode-ai).
   Free models and their terms: https://opencode.ai/docs/zen

THE CATCHES (with sources)
- Anthropic's docs say they do not support routing Claude Code to non-Claude models through any gateway: https://code.claude.com/docs/en/llm-gateway
- OpenRouter's own guide: Claude Code is only guaranteed to work with the Anthropic first-party provider.
- FreeLLMAPI README: "10.1 billion tokens per month" is a rough total across 87 providers; the README also says it is for personal experimentation and learning, not production.
- In my router test, requests went to keyless providers and carried about 12,000 tokens of prompt each. With those providers switched off, OpenRouter's daily free limit stopped two of three sessions ("Rate limit exceeded: free-models-per-day").
- OpenCode Zen docs: some free models are "free for a limited time" and may be used to improve the model; others state zero retention. Check per model.

Use your own free keys only. Never someone else's account or a leaked key. Read each provider's terms. Do not send client or company code through free services you have not checked.
