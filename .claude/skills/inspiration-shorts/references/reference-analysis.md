# Reference analysis (what was measured from the user's reference Short)

Five screen-recordings (~17 s each, order v2,v3,v5,v4,v1) = one ~87 s vertical Short, 24 fps, 9:16, flat 2D vector, all code/template-made. Structure: hook -> 4 colour-coded acts (Labor/Capital/Systems/Deals) -> recap -> question.

Techniques extracted (implemented originally in `engine/`):
- Gold gradient counter with dark outline + hard drop shadow, interpolating between values.
- Pill chips: thick dark outline, flat offset shadow, uppercase heavy sans, two-colour emphasis, parts that fill in on spoken words.
- Per-act background gradient (+ rays / stars), wipe/flash transition between acts, same layout in every act.
- Illustrations: flat fills, 7px ink outline, simple highlight; props pop/rise/slide in with overshoot (ease-out-back).
- Stamps that slam with scale-down + shake + flash; coin drops on income events; banner slides in for the lesson.
- Karaoke captions: dark rounded pill, active word highlighted, 2-3 words at a time.
- Progress rail with the four levels, active one lit.
- Voice: short declarative sentences, one fact per beat, "The lesson:" line per act, closing question.
Not copied: the character, the wording of chips and banners, the palette, the channel branding.
