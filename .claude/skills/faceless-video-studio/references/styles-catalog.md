# Short styles catalog (learned from reference channels; always build ORIGINAL versions)

| Style | Structure | Length | Narration | Effort | Built examples |
|---|---|---|---|---|---|
| A. Split-screen counters | Same trigger, two outcomes top/bottom, Day counters, one headline at a time, cold vs warm light, loop | 20-25s | none (music + sfx) | medium | pp-s01-same-advice |
| B. Fast narrated cartoon | Hook fact/line, one-word captions, new shot every 1-1.5s, colour per beat, twist payoff, loop | 30-40s | yes (~160-190 wpm) | medium-high  | (in owner's studio) |
| C. One-metaphor loop | One figure, one metaphor, pinned title with one highlighted word, loops | 12-18s | none | low  | (in owner's studio) |
| D. Multi-lane escalation | 3-4 labelled glowing figures, same start, Day counters, only one wins | 22-30s | none | medium  | (in owner's studio) |
| E. Second-person POV | "You" story, camera = viewer's eyes, hook text top, one-word captions, funny/relatable | 28-36s | yes | medium  | (in owner's studio) |
| F. Pick-one quiz | Question slam, two options, 3-2-1 countdown, reveal, "comment A or B", loop | 18-26s | none | low  | (in owner's studio) |
| G. Data explainer | Premise title, chart that changes with narration, VERIFIED numbers with sources.md | 30-45s | yes | high (research)  | (in owner's studio) |

Common rules: hook in the first second; a visible change every 1-2.5s; numbers move the direction the story says; payoff line last; last frame equals the first; no half-typed words; no placeholder text; vary topic, characters, palette and voice across uploads; label fiction as fiction, cite sources for real stories.

Locking: when several videos are built at once (4 cores), run EVERY render and mix through `flock /tmp/studio-render.lock ...` so they queue.

Review scorecard (0-5 each, pick the best 1-2 per week): hook in 1s; pace; caption legibility on a phone; correct directions; glitch-free (3 fps scan); audio mix; loop; originality; fit with channel.
