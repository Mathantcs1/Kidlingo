# Extending the engine (when a topic needs more than the built-in scenes)
All paths are under `$RC/engine/core/`.
1. **A scene** = depth planes, back to front, in `sketchsets2.js` (copy a similar one): `{ depth, draw(g,W,H) }` static planes, `{ depth, live(g,W,H,t,info) }` animated planes (stars, smoke, dust, glow), exactly one `{ depth: 0.65, figures: true }` where the cast stands. Size everything with `U(W,H)` (the frame's short side) so portrait and landscape both fit. Draw objects with the sketch kit (`sketch.js`: `shape`, `pencil`, `curvePts`...) and props (`props.js`, `props2.js`: add a new prop as a function `(g,x,y,s,seed)`).
2. **Register it:** export it from `SKETCH_SETS_MORE`; add its **look targets** (insert shots: name -> {x,y,depth} as fractions of the frame) in `sketchlooks.js`; add its staging (where a lead/crowd stands) in `STAGE` in `sketchlayout.js`. `tests/sketchworld.test.mjs` then checks it automatically (planes, looks, every cast kind inside the frame in portrait and landscape).
3. **A character:** add an entry to `CAST` in `cast.js` (skin, hair, hairStyle bun/toque/pigtails/cap/curls, outfit dress/chef/coat, height); to use it in scripts add its name to `cast` in `vocab.js` (`SKETCH_VOCAB.cast`) and place it in `sketchlayout.js`.
4. **A camera move:** add a name to `SKETCH_CAM_NAMES`, its shot size to `SHOT_SIZE`, and a `case` in `sketchcams.js`. `tests/operator.test.mjs` requires that it really moves.
5. Run `node --test tests/*.test.mjs`, build a draft, and LOOK at a contact sheet of the new scene in both formats before using it in a film.
