TradePulse — Deployment Steps

Neon PostgreSQL · Vercel · Google OAuth

1
Create Neon Database
  1. Go to neon.tech → Sign up / Log in
  2. Click New Project → name it (e.g. tradepulse)
  3. Region: US East (AWS)
  4. After creation, go to Connection Details
  5. Copy the Pooled connection string → this is your DATABASE_URL
  6. Copy the Direct connection string → this is your DIRECT_URL
⚠ The pooled URL contains pgbouncer=true and a -pooler subdomain. Keep both strings — Prisma uses them differently.
2
Push Code to GitHub
  1. Create a GitHub repo (e.g. Mathantcs1/Kidlingo)
  2. Push the project to branch claude/trading-journal-app-4Djdr
  3. Make sure vercel.json is present at the root:
{
  "buildCommand": "npx prisma generate && npm run build",
  "framework": "nextjs"
}
  1. Make sure prisma/schema.prisma has both url and directUrl:
datasource db {
  provider  = "postgresql"
  url       = env("DATABASE_URL")
  directUrl = env("DIRECT_URL")
}
3
Deploy on Vercel
  1. Go to vercel.com → Add New Project
  2. Import from GitHub → select the repo
  3. Vercel auto-detects Next.js — leave framework as is
  4. Before clicking Deploy, go to Environment Variables and add all variables (see Step 4)
  5. Click Deploy
  6. Note your live URL — e.g. https://kidlingo-rho.vercel.app
4
Set Environment Variables in Vercel

Go to Vercel → Project → Settings → Environment Variables and add:

DATABASE_URL        = postgresql://...pooler...?pgbouncer=true
DIRECT_URL          = postgresql://...direct...
AUTH_SECRET         = (run: openssl rand -base64 32)
AUTH_URL            = https://your-app.vercel.app
AUTH_GOOGLE_ID      = (from Google Cloud Console)
AUTH_GOOGLE_SECRET  = (from Google Cloud Console)
TWELVE_DATA_API_KEY = (from twelvedata.com — free account)
POLYGON_API_KEY     = (from polygon.io — free account)
ANTHROPIC_API_KEY   = (optional — for AI features)
OPENAI_API_KEY      = (optional — for AI features)
UPLOADTHING_SECRET  = (optional — for screenshot uploads)
UPLOADTHING_APP_ID  = (optional — for screenshot uploads)
⚠ After adding variables, redeploy from Vercel dashboard for them to take effect.
5
Run Database Migration
  1. The build command npx prisma generate && npm run build auto-generates the Prisma client
  2. For the first deploy, run migrations manually from your local machine:
npx prisma migrate deploy
  1. This creates all tables in the Neon database
  2. To seed an admin user (optional):
npx prisma db seed
6
Set Up Google OAuth
  1. Go to console.cloud.google.com
  2. Create a new project → APIs & Services → OAuth Consent Screen
  3. Choose External → fill app name + email → Save
  4. Add your Gmail as a Test User
  5. Go to Credentials → Create Credentials → OAuth Client ID
  6. Type: Web application
  7. Add these Authorized Redirect URIs:
https://your-app.vercel.app/api/auth/callback/google
http://localhost:3000/api/auth/callback/google
  1. Click Create → copy Client ID and Client Secret
  2. Paste into Vercel env vars as AUTH_GOOGLE_ID and AUTH_GOOGLE_SECRET
  3. Redeploy on Vercel
⚠ Common error — redirect_uri_mismatch: The URI in Google Console must match your live URL character-for-character (no trailing slash).
7
Verify Deployment
  1. Visit your live URL → you should see the TradePulse login page
  2. Register a new account with email/password
  3. Test Google sign-in — should redirect back to /dashboard
  4. Check Vercel logs if anything fails: Vercel → Project → Functions → Logs
  5. Check DB connection: Neon Console → Tables — all tables should be visible
